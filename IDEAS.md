# Идеи для масштабирования приложения

Список задумок на будущее — не в работе прямо сейчас, фиксируем, чтобы не забыть.

## 1. Раскрывающийся список товаров (группы, категории)
В экране менеджера (заказ на витрину) список товаров сделать сворачиваемым по категориям —
аккордеон вместо (или в дополнение к) плоского списка/вкладок-фильтров. Актуально, когда
товаров становится много и плоский список неудобно листать.

## 2. История заявок своей точки
Менеджер точки должен видеть историю своих прошлых заявок (что и когда заказывал), а не только
текущую активную заявку. Сейчас `orders` хранит только одну (текущую) заявку на точку — понадобится
отдельное хранилище истории по датам.

## 3. Автоматическое пуш-уведомление в Телеграм для подачи заявки
Бот сам напоминает точке подать заявку (например, если она ещё не подана к нужному времени).
Обязательно: кнопка в уведомлении, ведущая сразу к оформлению заказа — с одного тапа из
уведомления сразу в экран заказа, без лишних шагов. Требует Telegram-бота и Mini App
(см. план деплоя — уже обсуждали).
